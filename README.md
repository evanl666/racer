# Harbor Loop V0.9.5 — High-Speed Trails + Denser Traffic

V0.9.5 在 V0.9.4 高速曲线基础上加入速度拖影，将同屏 AI 从 18 辆小幅提高到 21 辆，并加入仅供本地试玩的循环背景音乐。低速时画面仍然清楚；进入中高速后，红车会逐渐出现沿真实历史路线绘制的残影。

## V0.9.5 新增

- 红车约从速度 `215` 开始出现轻微拖影，接近 `590` 时达到完整强度。
- 拖影使用过去数帧的真实位置，因此弯道和 0.05 秒快速变道时会自然跟随路线。
- 高速最多显示 5 层红车残影；撞车时立即清除，避免静止车辆仍有拖影。
- 玩家达到极高速后，黑色 AI 仅显示一层非常淡的残影，增加速度感但不干扰判断。
- AI 数量由 18 增至 21，只增加 3 辆，仍保留速度动态安全区和最多 2 辆同时变道的限制。

微信小游戏 / 浏览器玩法原型。


## 本地测试背景音乐

- 第一次按方向键、油门键或触摸变道时开始播放，不会违反浏览器/手机的自动播放限制。
- 音乐循环播放，默认音量为 `0.17`，让位于发动机、换道和超车反馈。
- 键盘按 `M` 可暂停或恢复音乐。
- 音乐文件位于 `assets/local/test_bgm.mp3`，为减小测试包已压缩到约 96 kbps；缺少文件时游戏会自动静音继续运行。
- `.gitignore` 已排除 `assets/local` 中的音频，因此执行 `git add .` 不会把测试歌曲提交到公开仓库。
- 当前 ZIP 是私人本地测试包；正式发布必须换成原创或已授权音乐。

## 本版重点

V0.9.4 根据实际试玩反馈重新设计速度曲线：普通超车只累计 Combo，永久速度只在每 10 辆时提升一档。

- 开局巡航速度保持 125，玩家仍需主动按油门追车。
- `x10 / x20 / x30...` 会触发一次明显的永久提速。
- 速度提升在约 0.4–0.7 秒内完成，不是瞬间跳帧，也不再分摊成每辆车几乎感觉不到的小幅增长。
- `x70` 巡航速度达到 515，按住油门可达 600；相比 V0.9.3 的 293/338 明显更快。
- 最高速度提高至 705，后期是真正的高速读车流阶段。
- 每 10 辆同时提高发动机基础转速，油门负责当前档位内的转速拉高与回落。
- 发动机由三层机械谐波与滤波噪声组成，减少之前单个合成器音符的感觉。
- 高速阶段扩大 AI 禁止变道安全区。
- 新增高速穿越检测，低帧率下红车不能直接穿过同车道黑车而漏判碰撞。
- 保留 V0.9.1 的六车道真实路面速度修复。

## 速度规则

| Combo | 松开油门巡航 | 按住油门最高 |
|---:|---:|---:|
| 0–9 | 125 | 175 |
| 10–19 | 180 | 240 |
| 20–29 | 240 | 310 |
| 30–39 | 305 | 380 |
| 40–49 | 365 | 445 |
| 50–59 | 420 | 505 |
| 60–69 | 470 | 555 |
| 70–79 | 515 | 600 |
| 80–89 | 555 | 640 |
| 90–99 | 590 | 675 |
| 100+ | 620 | 705 |

普通超车不会永久提高目标速度。跨过十辆节点后，红车使用更强的短时加速度追向新档位；因此 `x9 → x10`、`x19 → x20` 等节点应有清楚体感。

## 操作

### 浏览器 / 键盘

- `← / →` 或 `A / D`：即时变道。
- 按住 `↑`、`W` 或 `Space`：加油门。
- 松开油门键：回落到当前档位的巡航速度。
- `M`：暂停 / 恢复本地测试背景音乐。
- `R`：重新开始。

### 微信触屏

- 点击屏幕左半边 / 右半边：变道。
- 手机油门区域仍未加入；先完成键盘玩法和速度曲线验证。

## 声音逻辑

发动机现在包含：

1. 低频三角波，负责发动机主体。
2. 经过滤波的中频锯齿层，负责机械颗粒。
3. 较轻的高频谐波与带通噪声，速度和油门越高越明显。

发动机基础转速只在每 10 Combo 提高；按住油门会在当前档位内升转，松开后回落。发动机、换道和超车音仍为运行时程序合成；另外加载一份由用户提供并压缩到 96 kbps 的本地测试 BGM。

## 建议测试

1. 开局按住 `Space`，确认 125 → 175 的加速比 V0.9.3 更明确。
2. 观察 `x9 → x10`：车速和发动机基础转速应同时明显提升。
3. 继续到 `x30`，确认游戏已经进入明显高速状态。
4. 到 `x70`，确认红车速度显著高于 V0.9.3，而不是仍像中速巡航。
5. 在高 Combo 故意保持同车道追上黑车，确认不会因帧率而穿车。

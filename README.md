# Harbor Loop V0.8.1 — Minimal HUD + Input Fix

微信小游戏 / 浏览器原型。

## 本版重点

- 修复浏览器方向键偶发无响应：Canvas 自动获取焦点，并同时监听 Canvas 与 Window 的键盘事件。
- 支持 `← / →`、`A / D`，并兼容旧式 `keyCode`。
- 去掉顶部整条 HUD、速度、总超车、最高 Combo、Restart 按钮和底部左右按钮。
- 画面只在左上角保留一个紧凑的 Combo 数字。
- 手机使用隐形控制区：点击屏幕左半边或右半边即可换道。
- 赛道扩展为 8 段长直道和 7 个宽发卡弯，更充分利用竖屏空间。
- 继续保留 18 辆黑车、AI 预告变道、速度联动安全距离、分段加速和碰撞系统。

## 操作

- 键盘：`← / →` 或 `A / D` 变道。
- `R`：重新开始。
- 手机：点击屏幕左半边 / 右半边变道；画面没有可见按钮。

## 浏览器测试

1. 解压文件。
2. 双击 `index.html`，使用 Chrome 打开。
3. 页面打开后可直接使用方向键；点击画面后 Canvas 也会重新获取焦点。

## 微信开发者工具与发布

选择“小游戏”并导入本文件夹。正式发布前，将 `project.config.json` 中的测试 AppID 换为正式小游戏 AppID。

完整的注册、导入、手机预览、体验版、审核和发布步骤见：[`WECHAT_ONBOARDING.md`](WECHAT_ONBOARDING.md)。

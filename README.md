# Harbor Loop V0.7.2

微信小游戏 / 浏览器原型。

## 本版重点

- 黑车增加“玩家安全区”：红车接近时，黑车不会开始变道。
- 安全距离会随红车速度自动增加，后期高速状态会留出更长的反应距离。
- 黑车处于黄色方向灯预告阶段时，如果红车进入安全区，本次变道会取消。
- 已经实际开始横移的黑车不会突然反向，避免动画和碰撞判定异常。
- 保留无交叉环形赛道、14 辆黑车、Combo、分段加速和即时换道。
- 新增 `NOTES.md`，记录每一版的主要改动和当前设计决定。

## 动态安全距离

当前规则约为：

- 红车速度 155：安全距离约 46
- 红车速度 211：安全距离约 74
- 红车速度 262：安全距离约 100
- 红车速度 319：安全距离约 128
- 红车最高速附近：安全距离约 141

这不是碰撞距离，而是黑车“禁止启动变道”的提前保护范围。

## 浏览器测试

1. 解压文件。
2. 双击 `index.html`，使用 Chrome 打开。
3. 使用键盘 `← / →` 或 `A / D` 变道。
4. 按 `R` 重新开始。

## 微信开发者工具

选择“小游戏”并导入本文件夹。正式发布前，将 `project.config.json` 中的测试 AppID 换为正式小游戏 AppID。

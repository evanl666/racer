# Harbor Loop V0.6

微信小游戏 / 浏览器可运行原型。

## 本版变化

- 删除赛道中间原有的 6 条蓝色横线。
- 保留 1 条原创港口赛道和 6 条实际车道。
- 方向键左/右（也支持 A/D）在任何位置立即变道，动画约 0.05 秒。
- 黑色电脑车增加到 14 辆，暂时固定车道且比玩家慢。
- 每超过一辆黑车：Combo +1；Combo 1–8 每辆 +7，9–24 每辆 +3.2，25–60 每辆 +1.3，61 以后每辆 +0.55。
- 玩家初始速度从 165 微调为 155，最高速度为 345。
- 撞车后速度归零、Combo 清零、车身闪烁，然后恢复到基础速度。
- 显示本局通过车辆总数和最高 Combo。
- 点击 RESTART 或按 R 可以重新开始。

## 浏览器测试

解压后双击 `index.html`，建议用 Chrome 打开。

## 微信开发者工具

选择“小游戏”并导入此文件夹。测试阶段可使用测试 AppID；正式发布时把 `project.config.json` 里的 AppID 换成小游戏正式 AppID。

## V0.6.1 调整

- 只降低红车起始速度：165 → 155。
- 其余分段加速曲线不变，仍会快速进入高速状态。
- 黑车速度、即时换道和碰撞规则不变。
